## 🎨 2026 Design Trends Applied

### ✅ Glassmorphism
- Frosted glass backgrounds with `backdrop-filter: blur(10px)`
- Subtle amber borders (1px solid rgba(255, 165, 0, 0.15))
- Applied to cards, navbar, sidebar, dropdowns

### ✅ Grain Texture
- Subtle noise overlay on background
- Adds premium, tactile feel
- Non-obtrusive, doesn't distract

### ✅ Asymmetric Layout
- Generous negative space (2rem gaps)
- Unequal proportions for visual interest
- Floating elements with soft shadows

### ✅ Micro-Animations
```
fadeIn       → Page load reveal (0.6s)
slideInUp    → Card entrance from bottom (0.6s)
slideInLeft  → Sidebar entrance (0.6s)
slideInRight → Content entrance (0.6s)
scaleIn      → Element zoom (0.6s)
float        → Gentle breathing motion (3s)
glow         → Text shadow pulsing (2s)
```

### ✅ Rounded Corners
- Buttons & Inputs: 16px (radius-lg)
- Cards: 24px (radius-2xl)
- Small elements: 8-12px

### ✅ Floating Elements
- Card hover: Lift 8px + enhanced shadow
- Button hover: Lift 2px + glow
- Soft drop shadows (not harsh)

### ✅ Minimal Borders
- Uses spacing & shadows for separation
- Only amber accent borders (very subtle)
- Clean, modern appearance
